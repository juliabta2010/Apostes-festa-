Un paso de configuración en Supabase

Abre el SQL Editor de tu proyecto, pega y ejecuta este SQL para crear la tabla compartida y sus permisos:

create table if not exists public.party_records (
  collection_name text not null,
  record_id text not null,
  data jsonb not null default '{}'::jsonb,
  primary key (collection_name, record_id)
);
alter table public.party_records enable row level security;
grant select, insert, update, delete on public.party_records to authenticated;
create policy "Usuarios autenticados pueden leer apuestas"
on public.party_records for select to authenticated using (true);
create policy "Usuarios autenticados pueden crear apuestas"
on public.party_records for insert to authenticated with check (true);
create policy "Usuarios autenticados pueden actualizar apuestas"
on public.party_records for update to authenticated using (true) with check (true);
create policy "Usuarios autenticados pueden borrar apuestas"
on public.party_records for delete to authenticated using (true);

Las cuentas registradas en este proyecto compartirán la misma lista de apuestas. No compartas claves secretas.
